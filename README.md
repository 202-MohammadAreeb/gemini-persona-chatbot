# 💬 Gemini Persona Chatbot

An intelligent, persona-aware chatbot powered by Google's Gemini Pro and Gradio. Supports memory-based conversations, custom personas, and question-answering on uploaded PDF/TXT documents.


## 🚀 Features

- 🔁 **Multiple Personas**: Switch between Friendly, Sarcastic, Tech Support, Medical, and Fantasy Game Master modes.
- 🧠 **Session Memory**: Remembers user name and facts throughout the conversation.
- 📄 **Document Chat**: Upload a PDF or TXT and ask context-aware questions.
- 💡 **Gradio UI**: Clean and responsive frontend built with Gradio Blocks.

---

## 🛠️ Tech Stack

- Python 3.10+
- [Gradio](https://www.gradio.app/)
- [Google Gemini API](https://makersuite.google.com/)
- [pdfplumber](https://github.com/jsvine/pdfplumber)
- [python-dotenv](https://pypi.org/project/python-dotenv/)
